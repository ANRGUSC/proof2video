# Contributing

Keep the plugin useful across mathematical fields. Add a small independent
example or a regression test when changing a fragile part of the pipeline.
Do not couple the skill to one paper, model provider, or publication venue.

For mathematical examples, supply the exact claim, assumptions, derivation,
source mapping, and known limitations. For visual changes, inspect the final
encoded video; successful compilation alone does not verify typography.
For timing changes, test speech-cache reuse and caption/chapter alignment.

Run the unit tests and repository checker. Record actual end-to-end rendering
checks separately from automated tests. Keep generated media and model weights
outside Git and share them through release assets when appropriate.
